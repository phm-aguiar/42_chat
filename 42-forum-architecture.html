42 Chat + Forum Architecture

Monorepo Go + React + PostgreSQL — Chat em Tempo Real + Fórum Tech

Frontend — React + Vite

  • • Chat em tempo real (WebSocket)
  • • Forum (REST: boards → threads → posts)
  • • Tema brutalista 42 (Tailwind + Shadcn/ui)
  • • Auth OAuth2 com JWT integrado

Backend — Go 1.25 + Chi

  • • Chi router + gorilla/websocket + lib/pq
  • • Chat: WebSocket hub (broadcast em tempo real)
  • • Forum: REST CRUD (boards, threads, posts)
  • • Auth: JWT middleware + OAuth2 42 callback

Database — PostgreSQL 16

  • • users — autenticados via API 42 (INT ID)
  • • messages — chat em tempo real (existente)
  • •⭐ boards — categorias do fórum (UUIDv7)
  • •⭐ threads — tópicos (UUIDv7, bump order)
  • •⭐ posts — replies (UUIDv7, reply_to tree)
  • •⭐ board_staff — owner/mod/admin
