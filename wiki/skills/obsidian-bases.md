# obsidian-bases

> Cria e edita Obsidian Bases — tabelas dinâmicas dentro do vault.

## Localização
`.hermes/skills/obsidian/obsidian-bases/SKILL.md`

## Quando usar
- Criar visões tabulares de dados no vault
- Filtrar e ordenar notas por metadados
- Dashboards de acompanhamento de features

## Exemplo
Uma Base pode mostrar todas as features com colunas: ID, Status, Agentes envolvidos.
Filtrada por `tags: [sdd]`, ordenada por `created`.
