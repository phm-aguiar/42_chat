# git-conventional-commit

> Commits padronizados com secoes semanticas.

## Localizacao
`.hermes/skills/github/git-conventional-commit/SKILL.md`

## Quando usar
- Todo commit no framework
- `git-conventional-commit` → analisa mudancas e gera mensagem

## Formato
```
tipo: titulo curto

tipo:
 - item 1
 - item 2

docs:
 - item 3
```
