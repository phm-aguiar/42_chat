# Padrões Proibidos em Commits

Referência para o `git-conventional-commit`. Absorvido de `dev-git-commit-message` (AI-Agents-public).

## Mensagens Genéricas/Vagas

| Bloqueado | Correto |
|---|---|
| "Update files" | `docs: atualiza referências de API` |
| "Fix stuff" | `fix: corrige validação de token no middleware` |
| "Change code" | `refactor: simplifica formatação de datas` |
| "WIP" | `chore(wip): esboço inicial do orchestrator` |
| "temp" | Não commitar — usar `git stash` |

## Atribuição a Ferramentas/Assistentes

| Bloqueado |
|---|
| "Generated with Claude Code" |
| "Co-Authored-By: Claude <noreply@anthropic.com>" |
| "Generated by Copilot" |
| Qualquer atribuição a ferramenta/assistente no corpo do commit |

O commit é de autoria humana. Ferramentas são ferramentas.

## Marcadores de Work-in-Progress

| Ação | Padrão |
|---|---|
| WIP que vai ser squashado | `chore(wip): descrição` (permitido em feature branches) |
| Código temporário | `git stash`, não commitar |

⚠️ Commits WIP devem ser squashados antes do merge pra `develop`.

## Tipo Ausente

Commits sem prefixo de tipo (`feat`, `fix`, `docs`, etc.) são bloqueados.

## Regras de Formato

- Título: max 72 chars (ideal 50), lowercase, sem ponto final
- Seções: só incluir seções com itens. Nunca gerar seções vazias
- Ordem das seções: feat → fix → docs → refactor → test → chore → style
- Itens: dash + espaço, lowercase, sem ponto final

## Breaking Changes

Append `!` após o tipo/escopo: `feat!: remove deprecated API`

No formato squad:
```
feat!: remove endpoint legado de mensagens

feat:
 - remove POST /api/v1/messages (deprecated)
 - migra clientes para POST /api/v2/messages

BREAKING CHANGE: endpoint v1 removido. Clientes devem usar v2.
```

## Segurança

Commits NUNCA devem conter:
- Secrets, API keys, tokens, senhas
- Credenciais hardcoded
- Dados de usuário reais em exemplos
- Chaves privadas

Se um secret foi commitado por acidente:
1. Rotacionar a credencial imediatamente
2. `git filter-branch` ou `BFG Repo-Cleaner` pra limpar histórico
3. Documentar o incidente (sem expor o secret)
